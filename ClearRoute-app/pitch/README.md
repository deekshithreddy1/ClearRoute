# ClearRoute investor introduction

The 12-slide PDF is at `../output/pdf/clearroute-pitch.pdf`.
It covers the problem, product, customer requirements, delivery workflow,
pilot evidence, proposed business model, acquisition plan, positioning,
roadmap and founder ask. The appendix identifies sources and assumptions.

Rebuild on Windows with ReportLab installed:

```powershell
python pitch/build_pitch.py
```

The builder embeds Windows Arial fonts and checks text height and page bounds.
The screenshots are actual read-only captures of the local public funding page
on 8 October 2026. They contain no credentials, submitted request or live delivery.

Evidence uses the existing verification log and the user-provided Devnet journal.
The five confirmed service workflow steps are distinct from native CC delivery.
Pricing is proposed. No revenue, paid customers, signed partnerships or completed
external-wallet delivery is asserted. Update these claims only with evidence.

All 12 pages were rendered and visually reviewed for alignment, text fit and
legibility. A public deck should continue to omit tokens and private tracking URLs.
